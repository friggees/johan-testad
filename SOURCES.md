# Johan Testad — design concept

Source website: https://www.johantestad.com/ (retrieved 2026-09-23).
Portrait, project credits, contact address, Spotify artist link, Instagram, awards and biographical facts collected from this site. Copy rewritten for this concept. Director quotation is a 15-word excerpt from the testimonial on the original website.

Poster assets retrieved through IMDb's public title suggestion metadata; exact upstream image URLs and title IDs are recorded in research.json. Posters are owned by the respective rights holders. This concept uses them to illustrate the credited productions; usage permission should be confirmed by the site owner for final handover.

IMDb metadata lists The Swedish Connection and Synden / Land of Sin as 2026 releases; the original website still lists 2025. This design uses the release years from IMDb. Other project years follow the original site.

Music links verified through Spotify search results:
- Amat’s Lie: https://open.spotify.com/track/6IqY8x6NrdUZI9BvhuSPhU
- Örjan: https://open.spotify.com/track/5Spy39Gjyb7uYUgEMgMS2o
- Olyckan: https://open.spotify.com/track/2rcNw8j4l2tql42H9i3pOz

The website embeds official Spotify players only after a user activates a music button. No audio is self-hosted. Contact uses an honest mailto link; no form or simulated delivery. All poster links open the matching IMDb title. No analytics. Concept is noindex to avoid competing with the existing site.

Local development: npm run dev. Deployment: Vercel static output directory public.
